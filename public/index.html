Questions

Avant de te lancer.

Windows affiche « Windows a protégé votre ordinateur »

C'est normal pour un logiciel indépendant qui n'a pas encore de certificat payant. Clique sur Informations complémentaires, puis Exécuter quand même. Le fichier vient directement des releases GitHub de se7en.

Où trouver le code d'accès ?

Seventh OS est réservé à la team : demande ton code à la personne qui t'a envoyé ce lien. Tu ne l'entres qu'une fois, il reste ensuite protégé par Windows sur ton PC.

C'est vraiment gratuit ?

Oui. Pas d'abonnement, pas de pub. Les applis qui utilisent l'IA la font tourner sur ton propre PC.

Il me faut quel PC ?

Windows 10 ou 11, 64 bits. Certaines applis demandent plus : se7en Clip et se7en Censored conseillent une carte graphique, se7en IA a besoin d'After Effects. Chaque fiche dit ce qu'il faut.

Et sur Mac ou sur téléphone ?

Seventh OS et les applis tournent sur Windows. se7en Vision se pilote depuis ton téléphone, mais s'installe sur le PC.
